## Key Components Explained

### 1. **data_transformer.py** (180 lines)

**Purpose**: Convert pruned STIX graph to threat knowledge base

```python
transformer = DataTransformer(nodes_path, edges_path)
transformer.load_data()
threats = transformer.transform()
transformer.save_threat_kb(output_path)
```

**Output Format**: Unified threat records with:

- Attack patterns + MITRE IDs
- O-RAN component mappings
- Mitigations linked
- Keywords for search

---

### 2. **threat_knowledge_base.py** (350+ lines)

**Purpose**: Semantic search and knowledge base management

**Features**:

- ChromaDB integration (free vector database)
- Sentence-Transformers embeddings (no API key)
- CRUD operations (Create, Read, Update, Delete)
- Semantic search with relevance scoring
- Statistics and indexing

**Usage**:

```python
kb = ThreatKnowledgeBase()
kb.index_threats()
results = kb.search_threats("sandbox evasion", top_k=5)
kb.add_threat(threat_data)
kb.delete_threat(threat_id)
```

---

### 3. **rag_agent.py** (400+ lines)

**Purpose**: AI-powered threat analysis with Gemini API

**Pipeline**:

1. Receives attack description + indicators
2. Searches knowledge base for related threats
3. Sends context + indicators to Gemini API
4. Gets AI-generated analysis
5. Searches internet for novel threats (optional)
6. Generates comprehensive report

**Usage**:

```python
agent = RAGAgent()  # Requires GEMINI_API_KEY
result = agent.analyze_attack(
    attack_description="...",
    detected_indicators=[...],
    target_component="O-Cloud"
)
report = agent.generate_report(result)
```

```
GET     /api/threats/{threat_id}         - Get specific threat
POST    /api/threats                     - Create threat
PUT     /api/threats/{threat_id}         - Update threat
DELETE  /api/threats/{threat_id}         - Delete threat
GET     /api/stats                       - Get statistics
GET     /api/export/json                 - Export KB
POST    /api/import/json                 - Import KB
```

**Interactive docs**: http://localhost:8000/docs

## Architecture & Data Flow

### Data Transformation Pipeline

```
STIX Graph (nodes + edges)
        ↓
   DataTransformer
        ↓
Threat Records
   - Attack patterns
   - Mitigations
   - O-RAN mappings
   - Keywords
        ↓
 threat_knowledge_base.json
```

### RAG Query Pipeline

```
User Query (attack description + indicators)
        ↓
    RAG Agent
        ↓
        ├→ ChromaDB Search (semantic)
        ├→ Gemini API (analysis)
        └→ Internet Search (novel threats)
        ↓
  Comprehensive Report
   - Matched threats
   - AI analysis
   - Recommendations
   - Severity assessment
```

### HTTP Request Flow

```
Browser Request
        ↓
   FastAPI
        ↓
        ├→ Threat KB (search/CRUD)
        ├→ RAG Agent (analysis)
        └→ File I/O (import/export)
        ↓
    JSON Response
        ↓
   Browser Display
```

## Troubleshooting

### "GEMINI_API_KEY not found"

→ Create `rag/.env` with your API key

### "Knowledge base not initialized"

→ Run `python data_transformer.py`

### "Module not found"

→ Run `pip install -r requirements.txt`

### "Port 8000 in use"

→ Change port in `api_server.py` or kill process using port

### "ChromaDB errors"

→ Delete `rag/data/chromadb/` and reinitialize
